How Miguel’s language site finds information

Language context is requested directly from Wikipedia's public REST API. The starter phrases and word cards are curated, beginning-level practice material. Links always open the original source; no account or API key is required.

Internet content can be incomplete or imperfect. Treat it as a starting point, especially for grammar and usage.
